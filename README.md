### Compilers, native systems, and devices

- **[GB Recompiled](https://github.com/arcanite24/gb-recompiled)** — Static analysis and recompilation of LR35902 programs into reviewable C, backed by shared runtime devices, interpreter fallback, differential testing, deterministic captures, and native extension points.
- **[Crystal Recompiled](https://github.com/arcanite24/gb-recompiled/tree/main/ports/pokemon-crystal)** — A ROM-free source alpha built on GB Recompiled with semantic game-state views, transactional native tools, deterministic data mods, and controller-first Challenge Mode.
- **[CHIP-8 Recompiled](https://github.com/arcanite24/chip8recompiled)** — The smaller C/C++ static-recompilation toolchain that preceded GB Recompiled, with native executables, a multi-ROM launcher, debugging tools, and broad compatibility testing.
- **[Pokémon Platinum Portable](https://github.com/arcanite24/pokeplatinum-portable)** — Experimental SDL3 portability work built on the public Pokémon Platinum decompilation project. It remains source-only and contains no ROM.
- **[Sideband](https://github.com/arcanite24/sideband)** — An active TypeScript prototype for a controller-summoned Windows companion to Moonlight sessions, built around a resident runtime, manifest-driven plugins, and durable diagnostics.
- **Phobos ROM Manager** — A React Native handheld app plus Electron desktop companion for library management, LAN pairing, background queues, and off-device native-port builds. *Private prototype; public architecture write-up pending.*
- **Sheaf** — A quiet, e-ink-first Android reader for collaborative-fiction archives, with branch-selected offline libraries, change tracking, search, bookmarks, resumable downloads, and source-aware licensing. *Private 1.0 repository; public release pending.*
